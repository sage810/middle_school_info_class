🔍MISSION 5 — 형성평가: 오늘의 실력 점검

📢 오늘 배운 내용을 잘 이해했는지 스스로 확인해보자!

💡 O 또는 X 버튼을 눌러 골라보세요. 다 고르고 나면 '✅ 정답 확인' 버튼을 눌러 채점하고, '🔀 다시 풀기'를 누르면 처음부터 다시 풀 수 있어요.

1. 파일 확장자는 파일 이름 뒤에 점(.)을 찍고 붙는 글자들이다.

2. .jpg, .png는 이미지 파일의 확장자이다.

3. .mp3, .wav는 동영상 파일의 확장자이다.

4. .mp4, .avi는 동영상 파일의 확장자이다.

5. 화면을 캡처해서 저장한 파일은 보통 이미지 파일 확장자를 가진다.

6. 파일 이름의 확장자만 바꾸면 파일의 실제 종류도 바뀐다.

7. .exe 파일은 컴퓨터에서 실행되는 프로그램 파일이다.

버튼을 누르면 입력한 내용이 그대로 담긴 PDF 파일이 바로 다운로드돼요.
